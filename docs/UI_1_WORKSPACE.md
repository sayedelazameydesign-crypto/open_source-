## RESULT

- غلاف موحد: شريط جانبي RTL للحاسوب وقائمة `dialog` للهاتف، وروابط حقيقية فقط
  إلى مساحة العمل والمستندات. لا سجل عام أو إعدادات أو أزرار إلغاء شكلية.
- تصميم CSS موحد دون مكتبات تصميم أو خطوط خارجية أو اعتمادات تشغيل جديدة.
  لوحة مهمة مركزية ولوحة أدلة جانبية على العرض الكبير؛ تبويبات مهمة/نشاط/أدلة
  في العرض الضيق. التحول من تبويب الأدلة إلى الحاسوب لا يترك مساحة مهمة فارغة.
- فصل إنشاء الطلب والبث والاستئناف والموافقات وقراءة snapshot في hook مستقل.
  التحقق من استجابات API، تجاهل نتائج مهمة قديمة أو استجابة snapshot أقدم، منع
  الإرسال والموافقة المكررين، واستئناف SSE بالترقيم دون مضاعفة الأحداث.
  EOF ليس فشلًا ولا برهان اكتمال. تبديل مهمة **منتهية** إلى طلب جديد يمسح العرض السابق.
- خطة من بيانات الخادم فقط، وملخص نشاط دون عرض thought أو وسائط الأدوات أو raw logs.
  الحالات والأخطاء مسماة نصيًا؛ الموافقة المسجلة ليست دليل تنفيذ، ورفضها لا يُعرض نجاحًا.
- إفصاح واضح عن demo/scripted، وهوية منفذ من metadata لا من مقترح التوجيه.
  `completed` يعني نهاية دورة المحرك، وهدف المستخدم يظل `not_verified`.
- لوحة الملفات تستهلك metadata ومسارها الحقيقي. المسار العام يعيد **JSON metadata**،
  وليس تنزيل المحتوى؛ الرابط اسمه «فتح بيانات الملف». تنزيل Markdown الحقيقي في TXT.
- `/documents`: الهوية نفسها، تحقق من الاستجابات، أخطاء ودية بدل أخطاء الخادم الخام،
  خطة وموافقة ومعالجة حتمية محلية وتنزيل واسترجاع بمعرّف معروف. لم تُغيَّر معالجة الملفات.
- وصول أساسي: HTML دلالي، أسماء للحقول والأزرار، رابط تخطٍّ، تركيز مرئي، حصر تركيز القائمة،
  Escape، تنقل تبويبات بالسهمين RTL وHome/End، وتمييز المعرّفات LTR.

المتصفح Chromium **153.0.8010.0** مع Playwright **1.64.1**. إجمالي مجموعات
المتصفح **22**، وليس عدد assertions. كل manifests النهائية بلا pageErrors أو
unexpectedHttpErrors أو طلبات خارجية مرصودة. ذلك وصف للتغطية المسجلة لا ضمان شامل.

**تكامل المعاينة الحقيقي:** إنشاء `/runs` وReAct/flow/auto، SSE وإعادة اتصال EOF،
بدء مهمة جديدة بعد انتهائها، رفع TXT ثم عرض الخطة والتأكيد، GET download وContent-Disposition،
**النقر على رابط التنزيل وإتمام browser download**، مطابقة SHA-256 للبايتات المنزلة
والقيمة المعروضة، واسترجاع السجل بعد إعادة التحميل.

**الحقيقة المسجلة للأداة في المعاينة:** 1 نتيجة مسجلة، 0 ناجحة، 1 غير ناجحة.
ظهر إخفاق sandbox (`unshare ... Resource temporarily unavailable`) مع تحذير وعدم
ادعاء 5050 أو تحقق الحساب. لم يُخفَّف العزل لتغيير النتيجة؛ السبب الجذري غير متحقق.
المحرك اكتمل رغم إخفاق الأداة، والواجهة أبقت التمييز ظاهرًا.

**موافقات المنفذ:** احتاج هذا المسار fixture لأن demo العادي لا يطلب موافقة خطرة.
شُغِّل API حقيقي مؤقت بـQueueApprover وScriptedModel وأداة `test_approval_only`؛
تصنيفها DANGEROUS للاختبار فقط، وتنفيذها إرجاع نص عام وartifact في الذاكرة، بلا
شبكة أو shell أو نموذج خارجي أو أثر خطر. تأكد وصول approve وdeny من الزرين، ونتيجة
success/denied في snapshot، وعمل رابط metadata. لم يُستبدَل backend المعاينة.
أُوقفت خدمات الاختبار المؤقتة بعد الانتهاء.

**المحاكاة المعلنة:** تعذر الخلفية، طلب إنشاء مُجهض، استجابة إنشاء غير صالحة، تأخير
ومنع التكرار، انقطاع SSE وإعادة الاتصال وEOF أثناء running، snapshot غير صالح،
SSE تالف/مكرر/CRLF وذيل بلا فاصل نهائي، failed/cancelled/max_steps، استجابة TXT
مضللة، وغياب metadata في API قديم. ليست هذه أعطالًا عُرضت كوقائع إنتاجية.

## NEXT — الحدود والفجوات

- **NOT VERIFIED:** جهاز هاتف مادي، متصفحات أخرى، قارئ شاشة، تدقيق WCAG شامل،
  تحقق مستقل من المستخدم أو إنتاج/multiuser/multiworker أو هوية نموذج خارجي.
- النموذج في المعاينة **scripted**؛ الأدوات ليست دليل دعم عام لكل طلب أو تصفح حقيقي.
  رحلة TXT حتمية محلية بلا AI. نجاح اختبارات العرض لا يحول إخفاق sandbox إلى نجاح حساب.
- لا سجل عام من الخادم ولا استرجاع عام لمهام الوكيل بعد مغادرة الصفحة. «مهمة جديدة»
  متاحة بعد الحالة النهائية؛ لا تدعي إلغاء مهمة جارية. استرجاع TXT بمعرّف معروف متاح.
- موافقات الأدوات لا تعرض وسائط خام قد تحوي أسرارًا؛ التحذير يطلب الرفض إذا لم يكفِ
  اسم الأداة لفهم آثار الإجراء. تحسين ملخص موافقة آمن يحتاج عقد بيانات مدروس لاحقًا.
- التنزيل الحقيقي الحالي للتقارير في TXT فقط؛ artifacts العامة تعرض metadata لا محتوى.
  لا preview HTML أو تنفيذ محتوى ملف، ولا رفع متعدد الوسائط أو قدرات مراحل تالية.
- **تحذير أدوات:** البناء ناجح، لكنه يذكر غياب plugin الخاص بـNext في ESLint؛ الفحص
  المنفذ هو ESLint JS/TS وReact Hooks، لا حزمة قواعد Next الشاملة. إصدار ESLint 9
  المثبت يحمل أيضًا تنبيه انتهاء دعم من npm. لا يُعد PASS شهادة أمن أو وصول.
- **بوابة أمنية قبل الإنتاج:** `npm audit` يرصد 2 مدخلات (1 moderate، 1 high) في
  Next/PostCSS الحاليين؛ التفاصيل في `dependency-audit.json`. الاقتراح الآلي لترقية
  Next رئيسية لم يُنفّذ، ولم يُستخدم `audit fix --force`. يلزم تقييم وترقية مصرح بها.
- سياسة الاحتفاظ/TTL والحصص والحذف ما زالت غير منفذة في هذه المرحلة، ولم تُفتح أو
  تُنظَّف قواعد مستخدم قديمة. لا خدمات مدفوعة أو نشر أو commit/push.
